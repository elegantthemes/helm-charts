# DeepHive admission regression checks

Run `python3 tests/deephive-admission/check.py` from this repository with Helm,
Python/PyYAML and Go available. This renders the disabled-by-default chart using
synthetic settings and evaluates its admission expressions with pinned CEL-Go.
It never installs a policy or contacts a cluster. Dependencies are test-only.

`pod.json` is a representative manifest generated by DeepHive's `sessionPod`,
with the API server's default service account populated. Keep it aligned when
that pod contract changes. Checks cover a valid session, forbidden mounts,
credentials, identities, host access, labels and image replacements, plus cleanup
of an older approved image and metadata-only updates. Kubernetes API schema and
live admission enforcement remain separate cluster acceptance checks.
